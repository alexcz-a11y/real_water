# Limit quality guarantees to the Reference Experience

Real Water's visual-quality and whole-frame performance guarantees apply only to the controlled Reference Experience. Native Quality uses an exact 2560×1440 drawing buffer and render scale 1.0, native-resolution TRAA, SDR sRGB output, every in-scope effect enabled or deterministically triggered, and no TAAU, dynamic resolution, frame generation, or MSAA; auxiliary passes may use independently fixed resolutions only after final-image quality gates. Its presentation mode is evenly paced at 30 FPS while a separate uncapped run measures headroom, Chrome 151 is the certification browser, and Safari 27 receives a separate regression run. Cinematic Maximum may raise auxiliary quality without a frame-rate promise. Host Integrations receive documented interfaces, capability checks, quality controls, diagnostics, and module-level measurements, but their final image and application frame rate remain the host's responsibility.
