# Use batched hot runtime data contracts

Gameplay Queries use caller-owned typed arrays and return height, normal, three-dimensional surface velocity, foam, simulation tick, Artistic Control revision, and zero-or-one-tick local snapshot age without a GPU wait. Runtime Disturbances are batched radial impacts, directional wakes, foam bursts, and Hero Breakers, while registered Body sockets generate propeller and bow/stern effects automatically. Body attachments may be added or removed within prewarmed capacity, but their Interaction Shape is immutable for the lease. Environment scalars may update each physics tick, while replacing a texture identity, format, or size requires re-preparation. Artist-facing controls use perceptual language; internal numerical state remains engineering diagnostics, and audio is explicitly outside the first runtime while semantic events remain available to future host audio Adapters.
