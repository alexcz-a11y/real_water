# Separate browser acceptance, exploration, diagnostics, and certification

Real Water uses Playwright Test as the sole committed real-browser regression runner and direct QA Harness controller, agent-browser for agent-driven exploration and reproduction, Chrome DevTools MCP for Chrome diagnostics and performance evidence, and the reference M5 running the exact headed Chrome profile as the Native certification authority. These evidence classes do not substitute for one another: exploratory captures cannot satisfy regression gates, Playwright traces remain failure diagnostics rather than Native performance evidence, and diagnostic runs record their tool and browser versions while disabling CrUX lookup, redacting sensitive network headers, and keeping profiler-on and profiler-off results separate. Only Playwright is pinned as a repository dependency; auxiliary browser tools remain external unless a later demonstrated need reopens the no-overlapping-framework decision.
