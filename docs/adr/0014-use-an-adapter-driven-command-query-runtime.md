# Use an Adapter-driven command/query runtime

After preparation, Real Water exposes an Adapter-driven command/query Interface rather than public render or physics-step methods. Callers may update Artistic Controls and the Interaction Anchor, submit batched disturbances, attach bodies through Body Physics Adapters, perform allocation-free batched Gameplay Queries, inspect a lightweight snapshot, and dispose their leases; a read-only capabilities descriptor is the source for panels and capacity checks. Host Simulation, Environment, and Presentation are typed Host Lifecycle sub-seams: the Host owns 60 Hz physics and 30 FPS RenderPipeline ordering through Presentation bind, without a public `RealWaterLease.render`. Body Physics remains an additional real Adapter seam with production and memory implementations. Spectral simulation, local interaction, Three revision behavior, temporal histories, heavy GPU diagnostics, and all pipeline orchestration remain internal Implementation, and the core package imports no framework or rigid-body engine.
