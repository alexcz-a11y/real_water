# Define one host-driven Open Water runtime

Each WebGPURenderer may own one Real Water runtime and one active Open Water Domain in the first release. The domain is a horizontal Three.js XZ surface in a Y-up, one-unit-per-metre world, supports sea-level changes and host floating-origin shifts, and has one Interaction Anchor; tilted planes and multiple simultaneous oceans are excluded. The host supplies monotonic simulation time, pause state, camera, and a fixed 60 Hz physics cadence while the Reference Experience presents interpolated state at 30 FPS. Base spectral Gameplay Queries are synchronous and seed-matched on the CPU, local GPU interaction corrections may use the latest completed snapshot with at most one-frame latency, and the runtime never reads wall-clock time itself.
