# Stage delivery and gate the first public release

Implementation proceeds through workspace/prewarm/QA foundations, spectral Open Water and Gameplay Queries, optical and temporal rendering, local interaction and body coupling, whitewater and weather, underwater effects, Reference Experience UI and presets, imagegen-to-img2threejs demonstration assets, and finally M5 optimization and certification; proxy geometry prevents asset work from blocking the runtime. Local or preview `0.1.0-alpha.N` packages may support integration testing, but public 0.1.0 is blocked until Native visual, complete prewarm, public Interface, five-run M5 performance, Safari regression, documentation, effect-manifest, exclusion, compatibility, and license gates all pass. The first Reference Experience targets desktop keyboard and mouse only; mobile, touch, controller, XR, split-screen, and audio remain outside the release claim.
