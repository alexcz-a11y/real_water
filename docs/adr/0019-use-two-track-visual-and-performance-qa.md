# Use two-track visual and performance QA

GitHub Actions is a regression detector for type, build, manifest, deterministic runtime, loading, capability-rejection, and environment-specific WebGPU smoke tests; it never signs the Native Quality claim. A test-only browser Harness advances explicit 60 Hz ticks, fixed cameras, scheduled events, and named-buffer captures instead of waiting on wall-clock animation. The controlled M5 Mac in headed Chrome is the acceptance authority for Native screenshots, temporal artifacts, Chrome presentation traces, GPU attribution, and the five-run performance contract, with Safari measured separately; baselines never cross hardware, OS, browser, headless/headed, or software/hardware GPU profiles, and the machine remains manually triggered rather than an immediate self-hosted runner.
