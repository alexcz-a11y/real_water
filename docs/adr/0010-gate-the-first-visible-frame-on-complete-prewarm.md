# Gate the first visible frame on complete prewarm

The Reference Experience shows an independent Loading Experience until a fail-closed Readiness Gate proves that every pipeline, compute kernel, material variant, render target, asset, and conditional Native effect declared by the active Prewarm Manifest has been prepared. No partial 3D scene is exposed while compilation continues in the background; progress represents completed manifest work rather than a fabricated ETA, and failures remain on the accessible Loading Experience with cancel, retry, and copyable diagnostics. Each conditional route primes eight hidden history frames, performs a completion readback and main-camera guard frame, and reveals the 3D canvas only on the following refresh. Every page load repeats the gate, and an undeclared runtime variant fails with `EFFECT_NOT_PREWARMED` rather than compiling visibly. Reference assets are same-origin and hash-declared, Host Integrations supply verified assets before preparation, structural changes require a complete new preparation run, device loss returns the Reference Experience to one full rebuild attempt, and a long suspension re-enters the gate before visibility resumes.
